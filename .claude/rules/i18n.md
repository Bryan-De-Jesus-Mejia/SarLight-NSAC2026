# Idiomas: todo texto nuevo sale en español e inglés

La app (`ProyectoTal/`) funciona en español e inglés. **Cualquier texto que el usuario pueda ver, o que leería un lector de pantalla, se escribe con i18n desde el primer momento, en el mismo cambio.** No se deja "para después" ni se escribe en inglés plano dentro del JSX.

Guía completa: `ProyectoTal/i18n/README.md`.

## Regla de oro

La frase en inglés es la clave. El código dice el inglés y el español va en `ProyectoTal/i18n/es/*.ts`.

```tsx
const t = useT();                                  // en componentes ("use client")
<p>{t("Simple view")}</p>
t("{n} days later", { n: 12 })                     // marcadores {nombre}
t("{n, plural, one {# pass} other {# passes}}", { n })
rich(t("It flags <b>{area} km²</b>.", { area }), { b: (c) => <b>{c}</b> })   // import { rich } from "@/i18n/rich"
```

- Fuera de React (stores, `lib/*`, HTML del globo): `import { t } from "@/i18n/core"`.
- Textos fijos en constantes o tablas (listas, mapas, escenas): envuélvelos con `msg("…")` donde se declaran y tradúcelos con `t(valor)` al dibujarlos.
- Incluye también `aria-label`, `title`, `placeholder`, `alt`, mensajes de error y textos dentro de SVG.
- **Una frase completa por mensaje**, con `{marcadores}` para números, fechas y nombres. Nunca juntes trozos (`"Hay " + n + " casos"`) ni pases una plantilla con `${}` a `t()`: el español cambia el orden de las palabras.
- Plurales con `{n, plural, one {…} other {…}}`, no con `n === 1 ? …`.
- Fechas y números con `lib/format.ts` (`formatDate`, `formatNumber`, `formatValue`), no con `toLocaleString("en-US")` ni `toFixed` a mano para mostrar.
- Nombres de casos, regiones y países: `t(event.name)`, `t(event.region)`, `t(event.country)`; si hay un caso o un tipo nuevo, agrega su traducción en `i18n/es/data.ts`.
- Un componente que solo da formato pero no usa `t()` debe llamar a `useLang()` (o `useT()`) para redibujarse al cambiar de idioma.

## Al terminar cualquier cambio con texto

1. Agrega la traducción al español en el archivo de su área dentro de `ProyectoTal/i18n/es/` (créalo y regístralo en `index.ts` si es un área nueva). La clave debe ser **idéntica** al inglés, carácter por carácter.
2. Corre, desde `ProyectoTal/`:
   ```bash
   node scripts/check-i18n.mjs --raw
   ```
   - `MISSING`: texto con `t()`/`msg()` sin español. Debe quedar en **0**.
   - La lista `--raw`: inglés escrito directo en JSX sin `t()`. Envuélvelo (la marca "Dancing with the SARs" y nombres propios pueden quedar).
3. `npx tsc --noEmit` y `npx eslint` limpios.

El hook de fin de turno (`.claude/settings.json`) corre ese verificador y no te deja terminar mientras falten traducciones.

## Tono del español

Español neutro de la República Dominicana, claro y para estudiantes y maestros: frases cortas, sin tecnicismos innecesarios. Términos de radar usados en el proyecto: retrodispersión (backscatter), eco, pasada (pass), umbral (threshold), moteado (speckle), banda L/C, polarización cruzada, línea base (baseline). No inventes datos ni afirmes causas que el análisis no respalde: el texto en español dice lo mismo que el inglés.
